## 🚀 Setup & Upload
1. Clone repository via SSH:
   ```bash
   git clone git@github.com:iPranjalDas/Arduino-Flex-Sensor-with-Servo.git
   ```
2. Open primary `.ino` sketch in Arduino IDE.
3. Install required libraries.
4. Select COM port and target board, then click **Upload**.
